# Suporte

- Dúvidas, ideias e conversas: GitHub Discussions.
- Bugs reproduzíveis: GitHub Issues.
- Vulnerabilidades: use o relato privado de segurança; não abra uma Issue pública.

Ao relatar um bug, informe a versão do NFiles Radio, a versão do Windows, o resultado esperado e os passos para reproduzir. Não anexe bancos locais, tokens ou outros dados pessoais.
