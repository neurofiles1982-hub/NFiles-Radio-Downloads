Dados armazenados localmente

Configurações, estações, favoritos, históricos e cache de logos ficam no perfil local do Windows, em %LOCALAPPDATA%\NFilesRadio. Esses dados não são enviados ao mantenedor.

Conexões externas

Para funcionar, o aplicativo acessa os streams escolhidos, o catálogo público Radio Browser e, fora da edição Microsoft Store, o GitHub para verificar atualizações. Esses serviços podem receber dados técnicos normais de conexão, como endereço IP e agente de rede, conforme suas próprias políticas.

Suporte

Somente os dados enviados voluntariamente por e-mail, WhatsApp ou GitHub são recebidos pelo suporte. Evite compartilhar arquivos pessoais, senhas, tokens ou informações desnecessárias.

Exclusão

Históricos podem ser removidos no aplicativo. Após desinstalar, apague manualmente %LOCALAPPDATA%\NFilesRadio para remover os dados locais restantes.
